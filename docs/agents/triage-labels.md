# Triage labels

For local issues, record these values in the `Status:` line.

| Canonical role | Status value | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Needs maintainer evaluation |
| needs-info | needs-info | Waiting for reporter information |
| ready-for-agent | ready-for-agent | Fully specified for autonomous implementation |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be implemented |

When a skill requests a triage label, update the issue's status using this
mapping. Edit the status-value column if the repository's vocabulary changes.
