# Frontend

Vite, React Router, Tailwind and shadcn preset `beEgoEQi`. Use pnpm, with the version pinned in `package.json`.

```bash
pnpm install --frozen-lockfile
pnpm dev
pnpm check
pnpm build
```

FastAPI serves `dist` in production. See the [root README](../README.md) for Spotify setup, the Vite proxy and all development commands.
